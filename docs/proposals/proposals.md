# Proposals

Arguments for a change to plates, one file each — a case that may lose. The
list above holds every proposal, resolved or not: the index is the spine, and
what is unresolved is a view of it (`prov views proposals`, `dx tasks`). A
proposal closes by an edit that sets its `status` and names the release or
commit that resolved it, with the outcome in a **Status** section at the top
and the body left as argued.
