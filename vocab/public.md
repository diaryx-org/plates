# Public

Anyone at all, including people who will read it years from now and people who
were never meant to be the audience for anything. This repository is on GitHub
under MIT/Apache-2.0, so a document tagged `public` here is already world-
readable before any site is built — the tag says *this is meant to be read*, not
*this is now visible*.

Which makes the judgment an easy one to record: everything in this archive is
source, documentation or design notes for a tool. There is nothing here whose
disclosure could hurt anybody, and nothing that is anyone's but the author's.
The care goes the other way — into keeping it that way, which is what a closed
vocabulary on `audience:` is for.

The site built for this audience is `exports.docs`, fronted by the repository's
own README.
